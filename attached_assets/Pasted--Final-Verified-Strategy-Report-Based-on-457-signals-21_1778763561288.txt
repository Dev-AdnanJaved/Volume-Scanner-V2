## PART 3 — COMPLETE TRADING STRATEGY

### Entry Decision (entry-time fields only)

**Monster Score — 0 to 7 points:**

```python
def monster_score(signal):
    ad = signal['additional_data']
    score = 0

    # Strongest predictors
    if signal.get('price_change_24h', 0) > 15:        score += 2  # +30.7% edge
    elif signal.get('price_change_24h', 0) > 10:      score += 1  # +33.8% edge

    if signal.get('high_breakout_warning') == True:    score += 2  # counterintuitive but works

    # Market cap sweet spot
    mcap = ad.get('market_cap_usd') or 0
    if 10_000_000 <= mcap <= 100_000_000:              score += 1  # +24.9% edge

    # Momentum indicators
    if ad.get('ema50_distance_pct', 0) > 10:           score += 1  # +20% edge
    if (ad.get('funding_rate') or 0) > 0.01:           score += 1  # +19.9% edge

    return score  # max 7
```

| Score | Monster% | Fail% | Action |
|-------|----------|-------|--------|
| 6–7 | ~40%+ | <10% | Max size, target TP50–TP100 |
| 4–5 | ~25–35% | ~15% | Full size, target TP20–TP30 |
| 3 | ~15–20% | ~20% | Half size, exit at TP10 |
| ≤2 | <10% | >25% | Skip or tiny size |
